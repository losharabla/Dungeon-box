# Roguelike Prototype

## Game Design & Technical Design Document

## 1. Цель проекта

Создать небольшой законченный 2D roguelike-прототип на JavaScript, запускаемый непосредственно в браузере.

Главная цель первой версии — получить полностью играбельный игровой цикл:

**выбор персонажа → случайные комнаты → бои → получение оружия/ресурсов → магазин/лечение → босс → победа или смерть → новый забег.**

Проект должен быть простым для дальнейшего расширения.

---

# 2. Технологии

Использовать:

* HTML5
* JavaScript
* CSS
* HTML5 Canvas 2D API

Не использовать на этапе прототипа:

* React
* Vue
* Phaser
* Three.js
* внешние игровые движки
* внешние графические ассеты

## Визуальный принцип

**Никаких PNG/JPG-спрайтов для игровых сущностей.**

Все игровые объекты должны процедурно рисоваться средствами Canvas:

* персонажи;
* враги;
* боссы;
* оружие;
* пули;
* магические снаряды;
* эффекты;
* частицы;
* стены;
* декоративные элементы.

Можно использовать:

* `fillRect`
* `arc`
* `line`
* `polygon/path`
* `stroke`
* градиенты
* прозрачность
* вращение
* масштабирование
* частицы
* простые процедурные текстуры

Допускается использование CSS/SVG для элементов интерфейса, но игровой мир должен рендериться Canvas.

---

# 3. Визуальный стиль

Стилистика:

**dark fantasy / stylized 2D**

Игровое поле должно выглядеть как полноценная 2D-игра, а не как ASCII-графика или набор простых квадратов.

Даже если персонажи состоят из геометрических примитивов, они должны иметь:

* узнаваемый силуэт;
* голову;
* тело;
* конечности;
* оружие;
* анимацию;
* тень под ногами;
* визуальные эффекты атак.

Примерный визуальный подход:

* тёмные помещения;
* контрастные персонажи;
* яркие эффекты атак;
* частицы;
* вспышки;
* небольшие screen shake эффекты;
* glow через полупрозрачные слои;
* различные визуальные силуэты врагов.

Не требуется фотореализм.

Главное — **читаемость и ощущение настоящей 2D-игры**.

---

# 4. Игровой процесс

Прототип использует real-time combat.

Игрок:

* перемещается WASD;
* целится мышью;
* атакует ЛКМ;
* использует ульту Q;
* собирает оружие;
* собирает золото;
* посещает магазин;
* восстанавливает здоровье;
* проходит комнаты;
* сражается с боссом.

---

# 5. Основной игровой цикл

```text
Главное меню
     ↓
Выбор класса
     ↓
Начало забега
     ↓
Комната
     ↓
Бой / магазин / восстановление
     ↓
Награда
     ↓
Следующая комната
     ↓
Босс-арена
     ↓
Победа
     ↓
Следующий этаж / завершение прототипа
```

При смерти:

```text
Game Over
   ↓
Статистика забега
   ↓
Restart
```

# 6. Персонажи

Всего 3 класса.

## 6.1 Воин

Роль: melee bruiser.

Характеристики:

```text
HP: 150
Damage: 15
Movement Speed: 3
Attack Range: short
```

Особенности:

* высокий запас здоровья;
* сильные атаки;
* хорошая выживаемость;
* ближний бой;
* сильный knockback.

### Ульты

#### Whirlwind

Воин вращается и наносит урон всем врагам вокруг себя.

* большой радиус;
* высокий AoE damage;
* длительность около 2 секунд;
* персонаж может продолжать немного двигаться.

#### Invulnerability

Воин становится неуязвимым на короткое время.

* длительность: около 3 секунд;
* визуальный эффект вокруг персонажа.

#### Berserker Strike

Мощная атака по области перед персонажем.

* очень высокий damage;
* большой knockback;
* заметная анимация замаха;
* screen shake при попадании.

---

# 7. Маг

Роль: ranged AoE / control.

```text
HP: 80
Damage: 20
Movement Speed: 4
Attack Range: long
```

Особенности:

* низкий HP;
* высокий damage;
* дальний бой;
* контроль пространства;
* AoE.

### Ульты

#### Meteor

Игрок выбирает область.

Через короткую задержку туда падает метеор.

* огромный AoE;
* высокий damage;
* сильная вспышка;
* частицы;
* screen shake.

#### Chain Lightning

Молния поражает одного врага и перескакивает на ближайших.

* максимум 5 целей;
* damage уменьшается при каждом прыжке;
* яркий визуальный эффект цепи молний.

#### Time Stop

На несколько секунд останавливает всех врагов.

* враги перестают двигаться и атаковать;
* игрок продолжает двигаться;
* визуальный эффект замедления/остановки времени.

---

# 8. Стрелок

Роль: ranged DPS / mobility.

Это **оружейник**, а не лучник.

Использует огнестрельное оружие.

```text
HP: 100
Damage: 12
Movement Speed: 5
Attack Range: long
```

Особенности:

* высокая скорость;
* дальний бой;
* высокая скорострельность;
* сильная зависимость от выбранного оружия.

### Ульты

#### Bullet Storm

На короткое время выпускает большое количество пуль.

Пули направляются к курсору или веером вокруг игрока.

#### Ricochet

На несколько секунд пули начинают рикошетить от стен.

#### Combat Stim

Восстанавливает часть HP и временно увеличивает скорость движения.

---

# 9. Оружие

Всего:

**10 обычных оружий + 3 легендарных.**

Оружие должно существенно менять стиль игры.

## Обычные оружия

### Warrior

1. Sword

* средний damage;
* средняя скорость атаки;
* базовое оружие.

2. Battle Axe

* высокий damage;
* медленная атака;
* небольшой AoE.

3. War Hammer

* очень высокий damage;
* очень медленная атака;
* сильный knockback;
* шанс stun.

### Mage

4. Fire Staff

* огненные снаряды;
* оставляют небольшой burning effect.

5. Ice Staff

* меньший damage;
* замедляет врагов.

6. Lightning Staff

* быстрые снаряды;
* шанс дополнительного chain lightning.

### Gunner

7. Pistol

* высокая точность;
* высокая скорость атаки;
* небольшой damage.

8. Shotgun

* несколько дробинок;
* высокий damage на близкой дистанции;
* небольшая дальность.

9. Assault Rifle

* высокая скорострельность;
* небольшой damage одной пули.

10. Sniper Rifle

* очень высокий damage;
* низкая скорострельность;
* пробивает врагов.

---

# 10. Легендарные оружия

Легендарное оружие должно быть значительно сильнее обычного и формировать оптимальный билд конкретного класса.

## Warrior — Bloodthirster

Особенность:

**Убийство врага восстанавливает HP.**

Дополнительно:

* высокий damage;
* хорошая скорость атаки;
* healing on kill.

Идея:

> Чем агрессивнее игрок играет, тем больше он восстанавливается.

---

## Mage — Staff of the Void

Особенность:

Снаряды проходят сквозь врагов.

При попадании существует шанс создать небольшой взрыв.

```text
Enemy → Enemy → Enemy
          ↓
         EXPLOSION
```

Оружие особенно эффективно против групп врагов.

---

## Gunner — Hellstorm

Особенность:

**Чем дольше игрок непрерывно стреляет, тем выше скорострельность.**

После прекращения стрельбы бонус постепенно уменьшается.

Это оружие поощряет постоянное ведение огня и движение.

---

Всего 10 обычных типов.

## 1. Slime

## 3. Skeleton

## 4. Orc

* медленный;
* высокий HP;
* высокий melee damage.

## 5. Bat

* высокая скорость;
* периодически делает рывок к игроку.

## 6. Mage

* ranged;
* использует AoE атаки;
* старается держать дистанцию.

## 7. Shieldbearer

* имеет щит;
* блокирует атаки спереди;

## 8. Assassin

* телепортируется рядом с игроком;

## 9. Berserker

* сильный melee enemy;
* при низком HP получает увеличение скорости и damage.

## 10. Necromancer

# 12. Боссы

Всего 3 босса.

## Boss 1 — Stone Golem

Большой melee boss.

Атаки:

* обычный удар;
* удар по земле;
* каменные снаряды;
* призыв маленьких големов.

Фаза 2:

```text
HP < 50%
↓
повышение скорости
↓
более частые атаки
↓
больше AoE
```

Визуально должен быть значительно больше игрока.

---

# 13. Boss 2 — Fire Lord

Ranged/AoE boss.

Атаки:

* огненные шары;
* огненный дождь;
* стены огня;
* призыв огненных мобов.

Основная механика:

**игрок должен постоянно двигаться и избегать опасных зон.**

Фаза 2:

* больше огненных зон;
* более быстрые атаки;
* более короткие промежутки между атаками.

---

# 14. Boss 3 — Executioner

Финальный boss.

Большой melee/mobile enemy.

Атаки:

* dash;
* серия ударов;
* круговая атака;
* телепортация;
* призыв копий.

Фаза 2:

```text
HP < 50%
↓
повышенная скорость
↓
комбинации атак
↓
больше опасных зон
```

# 15. Типы комнат

Всего 4 типа.

## Arena

Основная боевая комната.

При входе двери закрываются.

```text
Wave 1
↓
Wave 2
↓
Elite Wave
↓
Victory
```

После победы:

* двери открываются;
* игрок получает награду;
* появляется возможность продолжить.

Награды могут включать:

* оружие;
* золото;
* случайный upgrade.

---

# 16. Healing Room

Комната без врагов.

При посещении:

* восстанавливает 30% максимального HP.

Также может содержать один небольшой случайный бонус:

* +10% max HP;
* +10% damage;
* +10% movement speed.

---

# 17. Shop

Комната без врагов.

Используется единая валюта — Gold.

Пример ассортимента:

```text
Sword             50 Gold
Potion            30 Gold
+10% Damage       80 Gold
+10% Speed        80 Gold
```

После покупки предмет исчезает из магазина.

---

# 18. Boss Arena

Специальная большая комната.

При входе:

* двери закрываются;
* появляется boss;
* начинается boss fight.

После победы:

* двери открываются;
* показывается экран победы;
* для дальнейшего расширения можно переходить на следующий этаж.

---

# 19. Генерация подземелья

Не требуется сложный procedural dungeon generation.

Использовать граф комнат.

Пример:

```text
        Shop
          |
Start — Arena — Arena
          |
         Heal
          |
        Arena
          |
         Boss
```

Каждый забег может иметь другое расположение комнат.

Минимальные правила:

```text
Start
 ↓
2–4 Arena
 ↓
Shop или Healing
 ↓
2–4 Arena
 ↓
Boss
```

В будущем систему можно расширить.

---

# 20. Прогрессия

На этапе прототипа не использовать полноценную систему уровней персонажа.

Сила игрока увеличивается посредством:

### Оружия

Основной источник изменения боевого стиля.

### Temporary upgrades

Примеры:

* +10% damage;
* +20 max HP;
* +15% movement speed;
* +10% critical chance;
* +20% attack speed.

Все бонусы действуют только в текущем забеге.

---

# 21. Ultimate System

У каждого класса есть 3 ульты.

Игрок выбирает одну ульту перед началом забега.

Ульта заряжается во время боя.

Заряд может увеличиваться за:

* убийства;
* нанесение damage;
* получение damage — опционально.

Когда заряд достигает 100%:

```text
ULT READY
```

Нажатие `Q` активирует способность.

# 23. Визуальный рендеринг

Каждая сущность должна иметь отдельную функцию отрисовки.

Пример архитектуры:

```js
drawPlayer(ctx, player)
drawWarrior(ctx, player)
drawMage(ctx, player)
drawGunner(ctx, player)

drawEnemy(ctx, enemy)
drawBoss(ctx, boss)

drawWeapon(ctx, weapon)
drawProjectile(ctx, projectile)

drawParticles(ctx)
drawEffects(ctx)
drawRoom(ctx)
```

Не использовать один универсальный прямоугольник для всех сущностей.

Каждый тип должен иметь собственный силуэт.

* небольшой flash;

* частицы;

# 26. Particles

Создать простой particle system.

Каждая частица должна иметь:

```js
{
    x,
    y,
    velocityX,
    velocityY,
    life,
    maxLife,
    size,
    type
}
```

Поддерживать:

* spawn;
* update;
* render;
* destroy.

Использовать систему для:

* ударов;
* смерти;
* огня;
* магии;
* выстрелов;
* взрывов;
* боссов.

# 30. Data-driven design

Игровые характеристики не должны быть жёстко прописаны внутри систем.

Например:

```js
const classes = {
    warrior: {
        hp: 150,
        speed: 3,
        damage: 15
    },

    mage: {
        hp: 80,
        speed: 4,
        damage: 20
    },

    gunner: {
        hp: 100,
        speed: 5,
        damage: 12
    }
};
```

Оружие аналогично:

```js
const weapons = {
    sword: {
        type: "melee",
        damage: 15,
        attackSpeed: 1
    },

    pistol: {
        type: "gun",
        damage: 12,
        fireRate: 5
    }
};
```

Добавление нового контента должно по возможности требовать изменения только data-файлов.

# 33. Что НЕ реализовывать в MVP

Не добавлять без явной необходимости:

* сюжет;
* NPC;
* диалоги;
* квесты;
* крафт;
* полноценное дерево навыков;
* permanent meta-progression;
* сохранения;
* multiplayer;
* online features;

# 35. Главный технический принцип

**Сначала сделать игру функциональной, затем красивой.**

Но визуальная система с самого начала должна быть рассчитана на процедурную 2D-графику.

Не создавать временную архитектуру, основанную на ASCII или цветных квадратах, которую потом придётся полностью переписывать.

Даже первый enemy должен сразу иметь отдельную функцию визуализации и собственный силуэт.

Цель:

> Получить небольшую, но визуально цельную 2D-игру, полностью работающую без единого внешнего игрового спрайта.

Если для какого-либо визуального элемента требуется сложный рисунок, сначала искать решение через Canvas primitives, paths, gradients, particles и procedural animation, а не добавлять image asset.

# 36. Definition of Done

Прототип считается рабочим, если новый пользователь может:

1. открыть игру;
2. выбрать Warrior/Mage/Gunner;
3. начать забег;
4. двигаться по комнате;
5. целиться мышью;
6. атаковать;
7. убивать врагов;
8. получать золото/награды;
9. подобрать оружие;
10. использовать ульту;
11. посетить Shop;
12. купить предмет;
13. восстановить HP;
14. пройти несколько случайных комнат;
15. дойти до Boss Arena;
16. победить босса;
17. увидеть Victory;
18. либо умереть и увидеть Game Over;
19. начать новый забег.

После выполнения этого списка **не расширять MVP автоматически**. Сначала проверить игровой цикл и только потом добавлять новый контент.
